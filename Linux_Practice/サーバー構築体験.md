# サーバー構築体験
---

本演習では, Linuxを使用したゲームサーバーの構築を目標として、linux操作、ネットワークの基礎知識を身につけます。

- 参考書は[こちらから(Linux, Linuxサーバー構築)](https://linuc.org/textbooks/linux/)
- ダウンロード不可能な場合は吉岡までご連絡ください
- Windowsユーザーはこの演習ではWSLを使用します。以下の手順に従ってインストールしてください

## 1. WSL（Ubuntu）のインストール手順

今のWindows 10/11なら、手順は非常にシンプルです。

### ステップ1：コマンドを叩く

1. **PowerShell**（またはコマンドプロンプト）を「管理者として実行」で開きます。
2. 以下のコマンドを入力してEnterを押します。
```powershell
wsl --install

```

> **何が起きる？**：WSLの機能を有効化し、さらに標準のLinux（Ubuntu）を自動でダウンロード・インストールします。

---

### ステップ2：PCを再起動する

インストールが終わると「再起動が必要です」と表示されるので、PCを再起動してください。

---

### ステップ3：初期設定（ユーザー名とパスワード）

1. 再起動後、自動的に黒い画面（Ubuntuのターミナル）が立ち上がります。
2. 「Enter new UNIX username:」と出るので、**好きな名前**（例: `taro`）を入力。
3. 次にパスワードを決めて入力します（**※入力中、文字は全く表示されませんが、しっかり入力されています**）。

これで完了です！

##### 注意!: パスワードとユーザー名は必ず忘れないように保管してください

---

## 2. 正しく入ったか確認する方法

PowerShellを開き、以下のコマンドを打ってみてください。

```powershell
wsl -l -v

```

以下のように表示されれば完璧です。

| NAME | STATE | VERSION |
| --- | --- | --- |
| **Ubuntu** | Running (またはStopped) | **2** |

---

## 3. 使用方法

### 1. 起動する方法

主に3つの方法がありますが、下に行くほどおすすめです。

* **スタートメニューから:** 「Ubuntu」を検索してクリック。
* **PowerShellから:** `wsl` と入力してEnter。
* **Windows Terminal (推奨):** Microsoft Storeから「Windows Terminal」を入れれば、タブでPowerShellとUbuntuを簡単に切り替えられます。

---

### 2. Linuxに入ったら最初にやること

Linux（Ubuntu）を使い始めたら、まずは中身を最新の状態に更新するのがマナーであり、安全策です。以下のコマンドを打ってみてください。

```bash
sudo apt update && sudo apt upgrade -y

```

> **豆知識:** `sudo` は「管理者権限で実行する」という意味です。パスワードを求められますが、入力しても画面には何も出ないので、気にせず打ち込んでEnterを押してください。

---

### 3. WindowsとLinuxでファイルをやり取りする

WSLの凄いところは、お互いのファイルに簡単にアクセスできる点です。

#### (1) WSLからWindowsのファイルを見る

WindowsのCドライブなどは、`/mnt/c/` という場所に繋がっています。

* デスクトップへ移動するコマンド：
`cd /mnt/c/Users/ユーザー名/Desktop`

#### (2) WindowsからWSLのファイルを見る

エクスプローラーのアドレスバーに以下を打ち込むと、Linuxの中身がフォルダとして現れます。

* `\\wsl$\Ubuntu`
* または、WSLのターミナルで `explorer.exe .` と打つと、今いる場所がWindowsのフォルダとして開きます。

---

### 4. 開発を爆速にする「VS Code」連携

プログラミングや設定ファイルの編集をするなら、VS Code（Visual Studio Code）との連携が最強です。

1. Windows側にVS Codeをインストール。
2. 拡張機能「**WSL**」（Microsoft製）を入れる。
3. WSLのターミナルで `code .` と打つ。

これだけで、「操作感はWindowsなのに、動いている環境はLinux」という理想的な開発環境が完成します。

---

### 5. よく使う管理コマンド (PowerShell側で実行)

WSLそのものを管理するときは、Ubuntuの中ではなく、**PowerShell**で以下のコマンドを使います。

| コマンド | 役割 |
| --- | --- |
| `wsl -l -v` | 動いているLinuxの状態（Running/Stopped）を確認。 |
| `wsl --terminate Ubuntu` | Ubuntuだけを強制終了する。 |
| `wsl --shutdown` | WSLの全機能を完全に停止する（メモリを解放したい時など）。 |

---

### 💡 覚えておきたいコツ

Linuxの勉強をする際、ファイルはなるべくLinux側（`/home/ユーザー名/` 以下）に保存するようにしてください。Windows側のフォルダ（`/mnt/c/...`）で作業することも可能ですが、読み書きのスピードが少し遅くなるという特性があり、お勧めしません!

---

### 補足：サーバー構築の勉強について

WSL上のUbuntuは、勉強用サーバーとして非常に優秀です。

* **練習に最適:** `sudo apt update` などのコマンドを叩いて、ApacheやNginx（Webサーバー）を入れる練習がすぐに始められます。
* **壊しても安心:** 万が一設定をめちゃくちゃにして壊してしまっても、Windows側からコマンド一つでUbuntuだけを消去して、サラピンの状態にやり直せます。
